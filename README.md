# Melting Point Chronicles

A Nigerian school RPG web prototype — anime vibes, Roblox freedom, Minecraft exploration, and full Pidgin energy. Made by Michael.

## What is this?

**Melting Point Chronicles** is a story-driven school adventure RPG set in a Nigerian secondary school in PH. Players pick a protagonist, explore the campus, talk to NPCs, complete quests, grow their Aura, and face off against the feared teacher Isi Owu.

## Key Technologies

- **TanStack Start** (React SSR framework)
- **TanStack Router** (file-based routing)
- **Tailwind CSS v4** + custom CSS (game UI styles)
- **React Context** (game state management)
- **localStorage** (auto-save and manual save)
- **Netlify** (hosting + serverless)

## Sections

| Route | Description |
|-------|-------------|
| `/` | Landing page — cover poster, stats, chapters, pidgin phrase bank |
| `/avatar` | Character selection — all 7 playable characters |
| `/game` | Main game — world map, joystick, NPC dialogue, HUD |
| `/gallery` | Character art gallery |
| `/credits` | Full cast, creator info, game credits |
| `/controls` | How to play, controls, game systems |
| `/settings` | Audio, graphics, language, save/reset |
| `/roadmap` | Development phases and upcoming features |

## Running Locally

```bash
npm install
npm run dev
```

App starts at `http://localhost:3000`.
